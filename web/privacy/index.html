Privacy

Last updated 13 October 2026

The generator

The address generator at the root of this site runs entirely in your browser. It makes no network requests during generation, loads no analytics or third-party scripts, sets no cookies, and is served with a Content Security Policy that forbids connections to anything but its own files. We cannot see the patterns you search for, the keys you generate, or that you visited at all beyond the ordinary server logs Cloudflare keeps for serving static files, which we do not read or export.

Cairn Pro orders

When you place a Pro order we store: the public key you generated, your target pattern, the unique payment address we derived for the order, the amount and asset, the offset our GPUs find, timing and attempt counts, and an email address only if you enter one. We do not store IP addresses, user agents, or your private key half, which never leaves your browser. Orders and their data are deleted 90 days after completion or expiry.

Teams jobs

API jobs store the deployer address, init code hash, target, the salt we find, and the API key that submitted them. Contact form messages store the email, company and message you type. API keys are stored hashed.

Payments

Payments are on-chain transfers to addresses we derive per order. We read public chain data to detect them through third-party RPC endpoints (Cloudflare Ethereum gateway, Base public RPC); those providers see the queries we make but receive nothing about you. We fetch the ETH/USD spot price from Coinbase's public API server-side at quote time.

Email

If you give an email for a "found" notification we send exactly one message when the job completes and nothing else. We never share or sell it.

Your rights

Email the address in the repository README to have an order's data deleted early. Because we store no identity beyond what you typed, deletion is by order link.
